刺猬选短信 · 三套结构，还没定稿

这是单独跑在 Docker 里的可交互原型，不改现在的 Android 应用，也没连真机短信。短信样本是虚构的。

现在的应用把「扫描 / 查看平台列表 / 查看卡槽 / 查看标签」分成四个底部入口。这三套都把主线收成一句：这张卡在哪些平台收过验证码，方便你自己去处理。

  • A 卡证账本：先选卡，再看这张卡的平台。扫描缩成一条状态。
  • B 证据卷宗：没有仪表盘。卡槽是档案目录，短信详情是一页摘录。
  • C 处理队列：先把对不上的确认掉，已识别的平台是一张自己去处理的清单。

用右下角黑条，或键盘 ← → 切换。右侧可以改扫描和权限，用来看边界，不是应用里的界面。
